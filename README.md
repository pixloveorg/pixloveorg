### Hi, this is [Pixlove](https://pixlove.org/) 💗

A free pixel-art editor that runs in the browser and installs as an offline app, with a community around it.

- 🎨 **Editor**: layers, animation frames and pixel-font text layers
- 🖼️ **Community**: a gallery, weekly challenges and live shared drawing rooms
- 📚 **Academy**: lessons that teach pixel art step by step
- ♟️ **Games**: [Chess](https://pixlove.org/games/chess), [Fort](https://pixlove.org/games/fort), [Troop](https://pixlove.org/games/troop), [City](https://pixlove.org/games/city) and [Mine](https://pixlove.org/games/mine), all drawn pixel by pixel
- 🌍 Available in 12 languages
